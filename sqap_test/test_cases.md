7.3 Spence Space 
# Prototype 1: 
1. Create Account
    - Create an account using email and password
2. Login
    - Login to existing account using email and password 
    - Successful login will send user to Spence Space Homepage
3. Navigation
    - Be able to navigate between the different My Fridges, Discover, Grocery List, and My Recipes pages
    - Each link should open the correct page and be able to return to homepage
4. Household Sharing
    - Create a household and owner should be able to access household information
    - Join an existing household using the invitation code
5. Recipe Favorites
    - Save a recipe to a user’s favorites and it will appear in My Recipes
    - Remove a saved recipe from favorites and it will no longer appear in favorites list
    - Saved favorites should remain the same after logging out and logging back in
6. Discover Recipe Page
    - Be able to view current available recipes
    - Select a recipe and it will show its details and required ingredients to make
	      
# Prototype 2: 
1. Household Sharing
    - Members of the same household should be able to view shared inventory and grocery list
    - Members of different households should not be able to view other households inventory or grocery list
2. Inventory Management
    - Be able to add food item to inventory and it will appear in inventory list
    - Be able to modify existing food item’s information
    - Can remove food item and it will no longer appear in inventory list
    - Make sure inventory changes stay saved after refreshing or exiting page
3. Barcode Scanner
    - Scan a supported food item’s barcode and verify that the items are correct
    - Scanned food information can be used while adding an item to inventory
4. Grocery List Maker
    - Add grocery items with quantity and should appear on list
    - Duplicate items should combine quantities regardless of capitalization
    - Be able to change quantities and remove items from list
    - If item is marked as bought will appear in previously bought section
    - Add Again will return previously bought item to grocery list
    - Household members should be able to view and have same grocery list
5. Recipe Search
    - Search for recipes using keywords and available ingredients
6. Perishable Item Tracker
    - Add or update food items with expiration information
7. Photo Receipt Scanner
    - A supported grocery receipt can be scanned and will identify and recognize scanned food items
    - Scanned food items can be added to inventory list
